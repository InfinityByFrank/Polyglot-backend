# backend-lab

Backend projects from [roadmap.sh](https://roadmap.sh/backend/projects), built step by step from beginner to advanced, in **Node.js, Java, Python and Rust**.

## About this repo

I'm using this repository to master backend development and to learn the languages I don't know yet. The idea is simple: build real projects, one at a time, and document what I learn along the way.

## How I'm working

1. Complete the projects from the roadmap.sh backend list, starting with the beginner ones.
2. Do them **all in one language first**, then move to the next one: Node.js → Java → Python or Rust.
3. Each project is self-contained, with its own README explaining how to run it and what I learned.
